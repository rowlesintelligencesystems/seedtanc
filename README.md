# 🌱 Seed Tanc - Intelligent Greenhouse CRM

**Autonomous, offline-first CRM and product innovation engine built on Firebase.**

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Configure Firebase:
   - Copy `.env.example` to `.env.local`
   - Add your Firebase credentials

3. Run locally:
```bash
npm run dev
```

4. Deploy to Firebase:
```bash
npm run deploy
```

## Features
- ✅ Firebase Authentication
- ✅ Real-time Firestore database
- ✅ Offline-first PWA
- ✅ React + TypeScript
- ✅ Tailwind CSS styling
